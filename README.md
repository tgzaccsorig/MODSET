# MODSET

Готовый прототип Minecraft Modpack Builder.

Открой `index.html` — сайт работает без установки Node.js.

Уже есть:
- выбор версии;
- Fabric / Forge / NeoForge;
- цели сборки;
- рекомендации модов;
- проверка/финальный экран;
- адаптив под телефон;
- тёмный gaming-дизайн.

Следующий этап — подключить Modrinth API, реальные зависимости и генерацию ZIP/.mrpack.
